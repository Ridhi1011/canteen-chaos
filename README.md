# Canteen Chaos — Bug Fixes

This repository contains fixes for the assigned bugs in the Canteen Chaos application.

## Fixes

- Fixed search suggestions appearing behind the category bar.
- Improved text readability in dark mode.
- Fixed menu overflow on smaller screens.
- Fixed unresponsive buttons on tablet screens.
- Fixed the sticky category bar on mobile.
- Added stock validation to prevent ordering unavailable quantities.
- Fixed stock restoration when orders are cancelled.
- Added coupon expiry validation.
- Fixed menu pagination.
- Corrected price sorting.

## Additional Fixes

- Fixed the My Orders page not displaying orders.
- Fixed order status transitions from ready to picked.
- Fixed coupon usage counts.

## Tech Stack

- HTML, CSS, JavaScript
- Node.js
